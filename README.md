## 这个仓库是什么

本仓库收录笔者在抖音电商一线实操中沉淀的 16 篇方法论文章（含店群铺货、千川投放、短视频、达人分销、选品打爆与类目案例）。内容全部来自真实店铺的实操复盘，包含可执行的步骤、真实的阶段数据与踩坑教训，不玩理论，只讲实操。

它同时是我的求职作品集之一，与我的抖音电商实习与创业经历互相印证：从直播工具、店铺运营到店群管理工具，我在一线亲手做过，也系统梳理过这一领域的完整经营图谱。

## 为什么把它放进产品作品集

这组文章不只记录“怎么运营”，也呈现我如何拆解经营目标、识别关键约束、设计动作链路并复盘结果。对产品经理而言，商业理解不是单独的一项知识，而是把用户、供给、流量、工具和收益放进同一套决策框架。

它与我的 AI 产品实践形成补充：AI 项目展示评测、上下文与可靠性，这个仓库则展示我对真实交易链路、商家经营和商业化场景的理解。

## 背景与署名口径

- 文章为**笔者抖音电商实操经历的方法论沉淀**；
- 文中数据均为**历史案例的当时口径**，不是统一实验结果，也不适合跨案例横向比较；
- 实际结果受类目、货源、平台规则和执行条件影响，请勿照搬预期；
- 所有文章以第一人称方法论口吻呈现，聚焦「方法可复用」，不构成收益承诺。
